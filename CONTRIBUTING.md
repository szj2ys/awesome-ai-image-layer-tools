# Contributing

Thanks for helping keep this list useful.

## What Fits

Add tools that support practical image-layer or design-recovery workflows:

- image-to-layers conversion;
- background, subject, object, or detail separation;
- transparent PNG/WebP, ZIP, PSD, SVG, or design-handoff export;
- image cleanup that helps designers rebuild assets from a flat file;
- open-source tools, public APIs, or public web products.

## Entry Style

Use one factual sentence:

```markdown
- [Tool Name](https://example.com/) - What it does, who it helps, and any real limitation such as upload, sign-in, credits, or paid plans.
```

Avoid hype words such as "best", "perfect", or "revolutionary" unless they are
part of the product name. If you are affiliated with a tool, disclose it in the
pull request.

## Pull Requests

- One tool per pull request.
- Search existing entries first.
- Link to the official website, docs, or repository.
- Keep descriptions short and honest.
- Mention whether the tool is free, paid, credit-based, local, hosted, or
  open-source when that detail matters.
